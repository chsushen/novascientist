# Security Policy 🔒

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.2.x   | :white_check_mark: |
| < 2.2   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within NovaScientist, please report it privately:

- **Do NOT open a public issue.**
- Email the maintainers or report via GitHub Private Vulnerability Reporting.
- Provide detailed steps to reproduce the issue.

We strive to respond and acknowledge receipt of security reports within 48 hours.
